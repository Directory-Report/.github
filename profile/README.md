# Directory Report

> One named Directory Report scan. Finish the size pass. Leave a note the next cleanup can read.

## Session Card

| Slice | What you do in Directory Report | What remains |
|-------|------------------------|--------------|
| Scan | Open Directory Report and name today's folder tree | A titled scan desk |
| Tree | Keep only live folders on the Directory Report board | A short size list |
| Export | Read Directory Report disk tree before you delete | A confirmed export list |
| Handoff | Mark finished scans inside Directory Report | A note for the next visit |

## How Directory Report Sits

Directory Report does not replace Explorer, the backup tool, or the recycle bin you already use. It sits beside them as a named scan desk for one job: which folder tree is live, which sizes still match the export list, and what the next person should read before cleanup.

A first visit should be one short size pass, then the same Directory Report scan desk the next day. That is enough to see if the disk tree holds.

## Traffic Light

| Signal | On the Directory Report board | What you do |
|--------|----------------------|-------------|
| Green | Named scan, short live folder list | Continue the same disk tree |
| Amber | Two drives mixed in one export list | Split the tree before cleanup |
| Red | No title, no note, folders unlabeled | Stop and name the scan first |
| Clear | Handoff written, live trees few | Close Directory Report and leave the desk |

## Open Order

1. Open the last Directory Report scan desk, not a new empty disk tree.
2. Read the folder sizes and the last handoff.
3. Finish one visible export list inside Directory Report.
4. Write what changed, then close with fewer unlabeled folders than you found.
5. If the tree feels crowded, drop anything that belongs to a different Directory Report drive.

## Desk Fit

| Who | What Directory Report holds |
|-----|--------------------|
| Cleanup desk | Folder sizes, disk tree, and the export you run |
| Shared PC | One Directory Report profile per person |
| Support | A repeatable Directory Report layout for the same scan |
| Home drive | Personal folders out of the work tree |

## After a Week

A week in Directory Report is not a larger unlabeled folder pile. It is the same title, a shorter live tree, and a note that still makes sense before the next cleanup. Take finished scans off the live set so the next visit starts on the disk tree that is still open.

Other programs stay where they are. Directory Report only keeps the path back: desk name, folder sizes, export list, handoff.

## Sign-off

- [ ] The Directory Report workspace name is short enough to scan
- [ ] Only live folders sit on the tree
- [ ] A second person can read the cleanup handoff
- [ ] The last Directory Report scan still opens after a restart
- [ ] Finished trees are off the live Directory Report set

## Field Note

Directory Report is easier to trust when the scan desk stays smaller than the drive it came from. Name the scan, keep the live folder sizes, finish one visible export, and write what changed.
